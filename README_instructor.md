## Before teaching

1. Complete the [Microsoft Productivity Accreditation 2026](https://learn.microsoft.com/en-us/training/paths/microsoft-productivity-accreditation-2026/) path yourself.
2. Confirm whether participants will have Copilot licenses; Lesson 6 has a path for each case.
3. Create the class Teams team and schedule the Session 2 meeting.
4. Re-check the links in the Workshop Plan resource list; Microsoft retires support pages often.
